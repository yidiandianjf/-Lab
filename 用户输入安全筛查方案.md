# 用户输入安全筛查方案

## 一、背景与目标

### 1.1 背景
本项目是一个AI阅读实验室教育场景应用，用户可以通过自然语言与游戏世界交互。为了确保平台内容安全合规，需要对用户输入进行筛查，阻止违法、违规或不当内容的输入。

### 1.2 目标
- 阻止违法、违规内容的输入
- 保护未成年人免受不良信息影响
- 符合国家相关法律法规要求
- 保持用户体验流畅性
违法内容包括：
    1.输入具有明显的hack、提示词注入、越权控制特征
    - 2.输入要求泄露协议、系统提示词或内部结构
    - 3.输入完全无法对应到当前上下文中的任何实体或行为
    - 4.存在涉黄涉政涉暴内容

---处理位置：gameengine.process_input到inputsystem.parse_input方法之间，进行筛查。


## 三、双层筛查架构设计

### 3.1 架构概览

## 四、第一层：关键词过滤实现

### 4.1 设计要点

1. **敏感词库管理**
   - 支持分类管理（政治、色情、暴力、赌博等）
   - 支持词库热更新（无需重启服务）
   - 支持自定义词库扩展

2. **匹配算法**
   - 精确匹配
   - 模糊匹配（处理变体、谐音、拆字等）
   - 正则表达式规则

3. **性能考虑**
   - 使用DFA（确定有限状态自动机）算法
   - 时间复杂度 O(n)，n为输入文本长度
   - 内存占用可控

## 五、第二层：AI智能筛查接口设计

### 5.1 设计要点

1. **模型要求**
   - 参数规模：约3B（如Qwen-3B、ChatGLM3-6B等）
   - 部署方式：本地部署或API调用
   - 响应时间：<500ms

2. **接口设计原则**
   - 抽象接口，便于替换不同模型
   - 支持同步和异步调用
   - 提供置信度评分

3. **筛查能力**
   - 语义理解：识别隐晦表达
   - 上下文分析：结合场景判断
   - 多维度评估：违法、违规、不当等

### 5.2 接口定义

```python
# src/security/ai_filter.py

from abc import ABC, abstractmethod
from typing import Optional
from dataclasses import dataclass
from enum import Enum


class RiskLevel(Enum):
    """风险等级"""
    SAFE = 0       # 安全
    LOW = 1        # 低风险
    MEDIUM = 2     # 中风险
    HIGH = 3       # 高风险
    CRITICAL = 4   # 严重风险


@dataclass
class AIScreenResult:
    """AI筛查结果"""
    is_safe: bool  # 是否安全
    risk_level: RiskLevel  # 风险等级
    confidence: float  # 置信度 (0-1)
    risk_categories: List[str]  # 风险类别
    reason: str  # 判断理由
    suggestion: str  # 处理建议


class AIScreenFilter(ABC):
    """AI筛查过滤器抽象基类"""
    
    @abstractmethod
    def screen(self, text: str, context: Optional[dict] = None) -> AIScreenResult:
        """
        筛查文本
        
        Args:
            text: 待筛查文本
            context: 上下文信息（可选）
            
        Returns:
            AIScreenResult: 筛查结果
        """
        pass
    
    @abstractmethod
    def is_available(self) -> bool:
        """检查模型是否可用"""
        pass


class LocalModelFilter(AIScreenFilter):
    """本地模型筛查器"""
    
    def __init__(self, model_path: str, device: str = "auto"):
        """
        初始化本地模型
        
        Args:
            model_path: 模型路径
            device: 运行设备 (auto/cpu/cuda)
        """
        self.model_path = model_path
        self.device = device
        self._model = None
        self._tokenizer = None
    
    def load_model(self):
        """加载模型"""
        # 由用户自行实现模型加载逻辑
        pass
    
    def screen(self, text: str, context: Optional[dict] = None) -> AIScreenResult:
        """执行筛查"""
        # 由用户自行实现筛查逻辑
        pass
    
    def is_available(self) -> bool:
        return self._model is not None


class APIModelFilter(AIScreenFilter):
    """API模型筛查器"""
    
    def __init__(self, api_url: str, api_key: str = ""):
        """
        初始化API模型
        
        Args:
            api_url: API地址
            api_key: API密钥
        """
        self.api_url = api_url
        self.api_key = api_key
    
    def screen(self, text: str, context: Optional[dict] = None) -> AIScreenResult:
        """调用API进行筛查"""
        pass
    
    def is_available(self) -> bool:
        return bool(self.api_url)
```

```python
# src/security/input_screener.py

from typing import Optional, Tuple
from dataclasses import dataclass
import logging

from .keyword_filter import KeywordFilter, FilterResult
from .ai_filter import AIScreenFilter, AIScreenResult, RiskLevel

logger = logging.getLogger(__name__)


@dataclass
class ScreenResult:
    """综合筛查结果"""
    is_blocked: bool  # 是否拦截
    layer: int  # 拦截层级 (1=关键词, 2=AI)
    reason: str  # 拦截原因
    user_message: str  # 用户提示信息
    detail: Optional[dict] = None  # 详细信息


class InputScreener:
    """输入筛查器 - 双层筛查主入口"""
    
    def __init__(
        self,
        keyword_config: str = "config/sensitive_words.json",
        ai_filter: Optional[AIScreenFilter] = None,
        enable_ai_filter: bool = True
    ):
        """
        初始化输入筛查器
        
        Args:
            keyword_config: 关键词配置文件路径
            ai_filter: AI筛查器实例（可选，用户自行提供）
            enable_ai_filter: 是否启用AI筛查
        """
        self.keyword_filter = KeywordFilter(keyword_config)
        self.ai_filter = ai_filter
        self.enable_ai_filter = enable_ai_filter and ai_filter is not None
        
        logger.info(
            f"输入筛查器初始化完成 - "
            f"关键词过滤: 启用, AI筛查: {'启用' if self.enable_ai_filter else '禁用'}"
        )
    
    def screen(self, text: str, context: Optional[dict] = None) -> ScreenResult:
        """
        执行双层筛查
        
        Args:
            text: 待筛查文本
            context: 上下文信息
            
        Returns:
            ScreenResult: 筛查结果
        """
        if not text or not text.strip():
            return ScreenResult(
                is_blocked=False,
                layer=0,
                reason="空输入",
                user_message=""
            )
        
        # 第一层：关键词过滤
        keyword_result = self._layer1_keyword_filter(text)
        if keyword_result.is_blocked:
            return keyword_result
        
        # 第二层：AI智能筛查
        if self.enable_ai_filter and self.ai_filter:
            ai_result = self._layer2_ai_filter(text, context)
            if ai_result.is_blocked:
                return ai_result
        
        # 通过所有筛查
        return ScreenResult(
            is_blocked=False,
            layer=0,
            reason="通过筛查",
            user_message=""
        )
    
    def _layer1_keyword_filter(self, text: str) -> ScreenResult:
        """第一层：关键词过滤"""
        result = self.keyword_filter.check(text)
        
        if result.is_blocked:
            logger.warning(
                f"关键词过滤拦截 - 词: {result.matched_words}, "
                f"分类: {result.category}, 级别: {result.level}"
            )
            return ScreenResult(
                is_blocked=True,
                layer=1,
                reason=f"命中敏感词: {', '.join(result.matched_words)}",
                user_message=self._get_block_message(result.category, result.level),
                detail={
                    "matched_words": result.matched_words,
                    "category": result.category,
                    "level": result.level
                }
            )
        
        return ScreenResult(
            is_blocked=False,
            layer=0,
            reason="关键词过滤通过",
            user_message=""
        )
    
    def _layer2_ai_filter(
        self, 
        text: str, 
        context: Optional[dict]
    ) -> ScreenResult:
        """第二层：AI智能筛查"""
        try:
            if not self.ai_filter.is_available():
                logger.warning("AI筛查器不可用，跳过第二层筛查")
                return ScreenResult(
                    is_blocked=False,
                    layer=0,
                    reason="AI筛查器不可用",
                    user_message=""
                )
            
            result = self.ai_filter.screen(text, context)
            
            # 根据风险等级决定是否拦截
            if result.risk_level.value >= RiskLevel.HIGH.value:
                logger.warning(
                    f"AI筛查拦截 - 风险等级: {result.risk_level.name}, "
                    f"类别: {result.risk_categories}, 置信度: {result.confidence}"
                )
                return ScreenResult(
                    is_blocked=True,
                    layer=2,
                    reason=result.reason,
                    user_message=self._get_ai_block_message(result),
                    detail={
                        "risk_level": result.risk_level.name,
                        "confidence": result.confidence,
                        "categories": result.risk_categories
                    }
                )
            
            # 中等风险记录日志但不拦截
            if result.risk_level == RiskLevel.MEDIUM:
                logger.info(
                    f"AI筛查警告 - 风险等级: {result.risk_level.name}, "
                    f"类别: {result.risk_categories}"
                )
            
            return ScreenResult(
                is_blocked=False,
                layer=0,
                reason="AI筛查通过",
                user_message=""
            )
            
        except Exception as e:
            logger.error(f"AI筛查异常: {e}")
            # AI筛查异常时，可选择放行或拦截
            return ScreenResult(
                is_blocked=False,
                layer=0,
                reason=f"AI筛查异常: {str(e)}",
                user_message=""
            )
    
    def _get_block_message(self, category: str, level: int) -> str:
        """获取拦截提示信息"""
        messages = {
            3: "您的输入包含不当内容，请修改后重试。",
            2: "您的输入可能包含敏感内容，请修改后重试。",
            1: "您的输入包含不适宜内容，建议修改。"
        }
        return messages.get(level, "您的输入未通过安全检查。")
    
    def _get_ai_block_message(self, result: AIScreenResult) -> str:
        """获取AI拦截提示信息"""
        return f"您的输入未通过安全检查。{result.suggestion}"
    
    def set_ai_filter(self, ai_filter: AIScreenFilter):
        """设置AI筛查器"""
        self.ai_filter = ai_filter
        self.enable_ai_filter = ai_filter is not None
        logger.info(f"AI筛查器已更新: {type(ai_filter).__name__}")
    
    def reload_keywords(self):
        """重新加载关键词库"""
        self.keyword_filter.reload()
        logger.info("关键词库已重新加载")
```

from src.security.input_screener import InputScreener, ScreenResult

class InputSystem:
    def __init__(self, io_system: IOSystem, screener: Optional[InputScreener] = None):
        self.io = io_system
        self.screener = screener or InputScreener()  # 使用默认配置
        logger.info("Input系统初始化完成")
    
    def parse_input(self, user_input: str) -> InputResult:
        """解析玩家输入（增加筛查）"""
        user_input = user_input.strip()
        
        if not user_input:
            return InputResult(
                input_type=InputType.BASIC_COMMAND,
                direct_response="请输入指令或自然语言描述。"
            )
        
        # === 新增：输入筛查 ===
        screen_result = self.screener.screen(user_input)
        if screen_result.is_blocked:
            logger.warning(f"输入被拦截: {screen_result.reason}")
            return InputResult(
                input_type=InputType.BASIC_COMMAND,
                direct_response=screen_result.user_message
            )
        # === 筛查结束 ===
        
        # 原有逻辑...
        if user_input.startswith("\\"):
            return self._parse_command(user_input[1:])
        
        return InputResult(
            input_type=InputType.NATURAL_LANGUAGE,
            natural_input=user_input
        )
